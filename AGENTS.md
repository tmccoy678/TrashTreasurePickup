# Contributor instructions

Preserve the product contract and validation expectations in [CONTRIBUTING.md](CONTRIBUTING.md).

## Agent skills

For issue/spec work, use the shared GitHub tracker described in [issue tracker](docs/agents/issue-tracker.md). For terminology or architecture decisions, follow [domain documentation](docs/agents/domain.md). Use the default triage-role names documented with the tracker.

Human-facing copy belongs in the README and linked author/support material. Operational changes belong in the skill and the relevant reference branch. Keep duplicated references byte-identical across the pair.
