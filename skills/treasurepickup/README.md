# Treasure Pickup

Open one Trash Pickup handoff, check the few live facts that matter, and reconstruct the next working context.

Install the pair from the [Pickup project](https://github.com/tmccoy678/TrashTreasurePickup), then invoke `$treasurepickup` in a fresh task. Supply the handoff and checkpoint, or start the task in the workspace containing `.pickup/`.

Treasure Pickup has no runtime dependency, registry, receipt service, lease, or freshness gate. Git history retains the former experimental implementation.
