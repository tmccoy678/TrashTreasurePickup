# Security Policy

## Supported versions

No versioned releases are published. Security fixes are provided only for the latest commit on `main`.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Earlier commits, forks, or modified copies | No |

## Private vulnerability reports

Do not disclose vulnerability details in an issue or pull request.

Contact [@tmccoy678](https://github.com/tmccoy678) through a private channel already established with the repository owner. If no private channel exists, open an issue containing only a request for a private security contact; do not include vulnerability details.

After private contact is established, include the affected commit, impact, reproduction steps, and any known mitigation.
